# Gemini de 0 a 100 🚀

Curso de Gemini en 20 sesiones de 15 minutos al día, preparado con cariño por su compañero de mesa para Néstor.

- `index.html`: la web (portada, lecciones, Nestómetro, insignias, examen y diploma).
- `contenido.js`: **todo el texto del curso**. Para cambiar una lección, edita solo este archivo.

El progreso se guarda en el navegador de quien hace el curso. No se envía nada a ningún sitio.

## Publicarlo con GitHub Pages
1. Sube estos archivos a un repositorio público.
2. En el repositorio: **Settings → Pages → Branch: `main` / carpeta `/ (root)` → Save**.
3. En un par de minutos estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
